H-ICE 🍦
WEB 224 Final Project
Created by: Deo118
Date: May 26, 2025

H-ICE is a responsive, single-page website designed for a fictional ice cream business. Developed as a final project for WEB 224, this site showcases a modern UI with interactive elements, including a video background, dynamic navigation, and a functional order form.

🚀 Features
🎥 Video Background: Engaging hero section with autoplaying background video.

📱 Responsive Design: Optimized for desktops, tablets, and mobile devices.

🎨 Custom Color Palette: Utilizes CSS variables for consistent theming.

🧭 Navigation Bar: Sticky top navigation with smooth scrolling.

📄 Privacy & Refund Policy: Dedicated section outlining policies.

🛒 Order Form: Interactive form for placing ice cream orders.

📷 Image Gallery: Showcases various ice cream flavors.

📍 Contact Information: Includes location, email, and phone details.
